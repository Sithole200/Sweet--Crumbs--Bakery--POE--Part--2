Sweet Crumbs Bakery Website
Project Description

Sweet Crumbs Bakery is a responsive bakery website created to provide customers with information about the bakery, its products, locations and ordering process.

The website presents a selection of cakes, cupcakes, pastries and seasonal specials. Customers can also view the shopping cart, make an enquiry and find the bakery's locations.

Website Pages

The website consists of the following pages:

- Home
- About Us
- Products
- Enquiry
- Contact

Home Page

The Home page introduces Sweet Crumbs Bakery and provides an overview of the bakery and its products.

About Us Page

The About Us page provides information about Sweet Crumbs Bakery, including:

- Our Mission
- Our Vision
- Our Team

The page also includes an image representing the bakery.

Products Page

The Products page displays the bakery's products and prices.

The products include:

Cakes
- Birthday Cake
- Wedding Cake
- Custom Cake

Cupcakes
- Vanilla Cupcakes
- Chocolate Cupcakes
- Red Velvet Cupcakes

Pastries
- Croissants
- Danish Pastries
- Chocolate Pastries

Seasonal Specials
- Seasonal Special

The page also includes a Shopping Cart section where customers can review products and proceed to the enquiry page.

Enquiry Page

The Enquiry page allows customers to provide their contact details and information about the products or custom orders they are interested in.

The form includes:

- Full Name
- Email Address
- Phone Number
- Product
- Quantity
- Event Type
- Event Date
- Preferred Flavour
- Special Requirements

Contact Page

The Contact page provides information about the bakery's locations.

The page includes:

- Johannesburg Branch
- Pretoria Branch
- Addresses
- Phone numbers
- Email address
- Opening hours
- Google Maps

Customers can also send a message through the contact form.

Technologies Used

The website was developed using:
- Visual Studio Code
- HTML5
- CSS3
- Google Chrome
- Google Maps

Design

The website uses a bakery-inspired design with soft colours, professional typography, responsive layouts and styled product cards.

The website was designed to provide a clean, simple and user-friendly experience.

Responsive Design

CSS media queries are used to make the website responsive across different screen sizes, including:

- Desktop
- Tablet
- Mobile devices

Images are also styled to resize appropriately on smaller screens.
